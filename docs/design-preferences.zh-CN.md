# 界面设计偏好：简洁、克制、低干扰

这份文档记录用户在 QiReader 桌面版中明确确认的审美与交互偏好，可直接用于后续界面设计、改版和 AI 提示。依据是本次实际反馈，不预设所有产品都必须使用同一种配色或布局。

## 核心品味

界面应让人关注正在做的事。用尽可能少的元素，清楚表达当前状态和下一步操作；提示被注意到即可，不需要成为视觉主角。

- **简单优先。** 能用窗口变暗和一句话表达，就做到这里。
- **视觉克制。** 避免显眼的大标题、渐变背景、发光装饰、庆祝图形、无必要的动画和大面积强调色。
- **文字精简。** 状态明确即可，使用「本轮完成」「继续」这样的直接表达。避免「这一轮，刚刚好」等氛围文案。
- **减少重复。** 灯已经表达进度时，顶部只留灯，不再叠加进度文字；完成提示也不必重复展示整排灯。
- **沿用当前界面。** 提示出现时让原窗口变暗，保留原页面作为背景，不额外切换成一张精心装饰的全屏页面。

## 简单的外观，明确的交互

简化视觉时，保留必要的状态反馈和操作边界。

- 每次实际打开文章就点亮对应的灯：第一篇亮第一盏，打开本轮最后一篇时点满并提示。后台预加载不点灯。
- 完成提示出现后暂停翻篇，不能连续按空格就进入下一轮。
- 用户点击继续、关闭提示或按明确的确认快捷键后，才进入下一轮。
- 目标数量允许自定义；新增样式可切回原样式。
- 必要的错误信息、键盘操作、焦点提示和可读性应保留。

这些是本次阅读器已经确认的交互要求，其他产品复用时应结合实际任务调整。

## 已验证的例子

| 方案 | 用户反馈与结论 |
| --- | --- |
| 暗幕中央放白色卡片、成功图标、说明文字 | 用户认为不好看；不要把通用成功弹窗当作默认答案。 |
| 深绿全屏背景、大标题、装饰灯列、较大的继续按钮 | 用户认为过于显眼；视觉设计做得更多不代表更符合偏好。 |
| 当前窗口变暗，小字「本轮完成」、朴素的继续按钮和简短快捷键提示 | 用户明确认可：「这样就很好」。以 QiReader Desktop 0.19.1 为参考。 |

用户原话：「过于显眼了，就是窗口变暗，越简单越好，不要花里胡哨的。」

## 可直接复用的设计指令

```text
按我的界面偏好设计：简洁、克制、低干扰。
用最少的视觉元素表达状态和下一步操作，让内容保持主角。
提示优先采用原窗口变暗、简短状态文字和一个朴素的主操作。
避免渐变、大标题、装饰图形、庆祝效果、无必要的动画和氛围文案。
已有图形能表达的信息，不再重复堆文字。
保留清晰的操作边界、必要的错误反馈和键盘可访问性。
参考 QiReader Desktop 0.19.1 的轮次完成提示。
```

交付前检查：是否还能删除装饰、缩短文字、减小强调，同时让状态和操作依然清楚？如果可以，就继续简化。
